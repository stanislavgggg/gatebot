# Gate Bot — двойной гейт подписки + бонус-хаб + рассылки

Один бот вместо покупки трафика в каждый канал отдельно.

**Воронка:** FB-реклама → бот → подписка на оба канала ГЕО (казино + беттинг)
→ доступ к бонус-хабу → юзер в базе → рассылки в личку.

Один оплаченный клик = две подписки + контакт в базе.

---

## Что умеет

| Функция | Как работает |
|---|---|
| **Двойной гейт** | Требует подписку на все каналы ГЕО, проверка через `getChatMember` |
| **Мульти-ГЕО** | LV и LT из коробки, новое ГЕО = блок в `config.py` + переменные |
| **Deep-link атрибуция** | `?start=lv_fb_casino_cr3` → geo=lv, source=fb_casino_cr3 |
| **Бонус-хаб** | Категории казино/ставки, офферы из `bonuses.json` |
| **Локализация** | LV → латышский, LT → литовский, английский как фолбэк |
| **Текст под креатив** | Казино-ссылка → казино-текст, беттинг-ссылка → беттинг-текст |
| **Картинка в гейте** | Файл из папки `image/`, отдельно под ГЕО и вертикаль |
| **Трекинг кликов** | Каждое открытие бонуса пишется в БД — видно, что реально интересно |
| **Рассылки** | Конструктор аудитории: ГЕО × метка креатива × канал × клики × статус × активность |
| **Сегмент по каналу** | Подписка пишется по каждому каналу отдельно — видно, кто в казино-канале, кто в беттинг-канале |
| **Тест-режим** | Себе, на 10 юзеров, переписать — до боевой отправки |
| **Статистика** | `/stats` — конверсия гейта, разбивка по ГЕО и источникам, топ бонусов |
| **Обновление бонусов** | `/reload` перечитывает JSON без рестарта |

## Деплой на Railway

### 1. Создать бота
@BotFather → `/newbot` → скопировать токен.

### 2. Добавить бота админом в КАЖДЫЙ канал
Без этого `getChatMember` вернёт Forbidden и гейт не заработает.
Достаточно минимальных прав (можно снять всё, кроме присутствия в админах).

### 3. Узнать chat_id каналов
Переслать любой пост из канала боту @getmyid_bot. Формат: `-100xxxxxxxxxx`.
Свой ID для `ADMIN_IDS` — у @userinfobot.

### 4. Залить репозиторий
```bash
git init && git add . && git commit -m "init"
git remote add origin <твой-репо>
git push -u origin main
```
Railway → New Project → Deploy from GitHub repo.

### 5. Подключить Volume (обязательно!)
Railway → Volumes → Add Volume, mount path `/data`.
Затем переменная `DB_PATH=/data/bot.db`.

**Без этого база пользователей сотрётся при первом же редеплое.**

### 6. Прописать переменные
Скопировать всё из `.env.example` в Railway → Variables, подставив свои значения.

### 7. Проверить
Логи должны показать `Бот @yourbot запущен`. Дальше в боте: `/start` → `/links`.

## Ссылки под Facebook-кампании

Команда `/links` в боте выдаёт готовые ссылки. Формат:

```
https://t.me/yourbot?start=lv                    базовая
https://t.me/yourbot?start=lv_fb_casino          казино-креативы LV
https://t.me/yourbot?start=lv_fb_betting         беттинг-креативы LV
https://t.me/yourbot?start=lv_fb_casino_cr3      конкретный креатив
```

Первая часть до `_` — код ГЕО (определяет, какие каналы требовать).
Всё остальное пишется в `source` и видно в `/stats`.

Гейт одинаковый для всех источников внутри ГЕО (оба канала),
но метка позволяет считать конверсию по каждому креативу отдельно
и сегментировать рассылки.

## Текст и картинка под креатив

Гейт подстраивается под вертикаль, определённую из метки ссылки:

| Ссылка | Текст гейта | Каналы |
|---|---|---|
| `?start=lv_fb_casino` | про казино-бонусы и фриспины | оба (LV) |
| `?start=lv_fb_betting` | про фрибеты и коэффициенты | оба (LV) |
| `?start=lv` | общий про бонусы и ставки | оба (LV) |

**Каналы в гейте всегда одни и те же для ГЕО** — меняется только копирайт
и картинка, чтобы посадка совпадала с креативом. Так связка «реклама → бот»
не рвётся, а метка всё равно пишется в `source` для аналитики.

Вертикаль ловится по подстроке: `casino`/`slots` → казино,
`betting`/`bet`/`picks`/`sport` → ставки. Не распознали — общий текст.

### Картинки

Положить в папку `image/`, поиск от точного к общему:

```
image/gate_lv_casino.jpg    ГЕО + вертикаль
image/gate_lv.jpg           только ГЕО
image/gate_casino.jpg       только вертикаль
image/gate.jpg              общий фолбэк
```

Форматы `.jpg` `.jpeg` `.png` `.webp`. Файла нет — уйдёт просто текстом.

Текст гейта становится подписью к фото (лимит Telegram — 1024 символа,
текущие тексты укладываются с запасом).

## Языки

Тексты для пользователя лежат в `locales.py`:

| ГЕО | Язык |
|---|---|
| `lv` | латышский |
| `lt` | литовский |
| остальные / не определено | английский |

Админка (`/stats`, `/broadcast`) осталась на русском — она только для своих.
Добавить язык: скопировать блок в `LOCALES` и поменять код ГЕО.

Названия и описания бонусов берутся из `bonuses.json` — там текст пишется
сразу на нужном языке, отдельно для каждого ГЕО.

## Обновление бонусов

Правишь `bonuses.json` → пушишь в репо → Railway передеплоит → `/reload` в боте.
Либо монтируешь файл в Volume и правишь без редеплоя.

```json
{
  "lv": [
    {
      "id": "уникальный_id",
      "brand": "1xBet",
      "title": "Заголовок",
      "description": "Условия",
      "url": "https://твоя-affiliate-ссылка",
      "vertical": "casino",
      "expires": "2026-12-31"
    }
  ]
}
```

`expires` в прошлом → бонус автоматически скрывается.
`/reload` предупредит о тех, что протухают в ближайшую неделю.
Битый JSON не уронит бота — останется последняя рабочая версия.

### Как отвечать юзерам

Всё, что юзер пишет боту, автоматически прилетает админам: сначала шапка
(имя, username, ID, ГЕО, источник, статус гейта), следом само сообщение.

**Ответить** — просто reply на любое из этих двух сообщений. Ответ уйдёт
этому юзеру от имени бота, с медиа и форматированием.

Альтернативы, если сообщение потерялось в чате:
- `/inbox` — список тех, кто писал, свежие сверху
- `/find ivan` или `/find 12345678` — найти юзера
- `/dialog 12345678` — посмотреть переписку
- `/msg 12345678 текст` — написать напрямую по ID

Если юзер заблокировал бота, ответ не уйдёт — бот скажет об этом
и пометит его в базе, чтобы он не попадал в рассылки.

### Как делать рассылку

1. `/broadcast` → открывается конструктор аудитории:

```
🎯 Audience
GEO: 🇱🇻 Latvija
Ad label: Casino, Betting, None
Status: Passed the gate
Channel: In the casino channel
Interest: Clicked casino bonuses
Activity: All time

[✅ 🇱🇻 LV] [⬜️ 🇱🇹 LT]
[✅ 🎰 Casino] [✅ ⚽ Betting] [✅ ❓ None]
[✅ Passed the gate]
[📡 In the casino channel]
[👆 Clicked casino bonuses]
[📅 All time]
[📨 Recipients: 412 — continue]
```

ГЕО и метки креатива — тумблеры, жмёшь и снимаешь галочки.
Остальные строки переключаются по кругу.
**Счётчик получателей пересчитывается на каждое нажатие** — видно размер
сегмента до того, как что-то отправишь.

### Чем отличаются три «казино» в фильтрах

Легко перепутать, поэтому по порядку:

| Фильтр | Что означает | Откуда данные |
|---|---|---|
| **Ad label** | В deep-link ссылке была метка `casino` / `betting` | Метка креатива, `?start=lv_fb_casino` |
| **Channel** | Юзер реально подписан на казино-канал / беттинг-канал | `getChatMember` по каждому каналу |
| **Interest** | Юзер открывал казино- или беттинг-бонусы в боте | Клики по кнопкам бонусов |

**Ad label** заполняется только у тех, кто пришёл по размеченной ссылке —
органика и переходы из канала попадут в «None». Это фильтр про источник
трафика, а не про интересы человека.

**Channel** — факт подписки. Гейт требует все каналы ГЕО сразу, поэтому у
прошедших гейт в LV будут отмечены оба канала. Ценность фильтра — в связке со
статусом «Did not pass the gate»: `Channel: Casino channel only` +
`Did not pass the gate` = подписался на казино-канал, но на пикс не стал.
Готовый сегмент, чтобы дожать вторую подписку.

**Interest** — самый честный сигнал: человек не просто подписался, а нажал на
конкретный оффер. `Never clicked a bonus` — те, кто прошёл гейт и пропал:
хороший сегмент под реактивацию.

Комбинации, которые нужны чаще всего:

```
LV + Passed the gate                          все латвийцы с доступом
LV + Clicked casino bonuses                   латвийцы с интересом к казино
LV + Casino channel only + Did not pass       дожать подписку на LV PICKS
LV + Never clicked a bonus + Active in 30 days  реактивация
```

### Подписки по каналам в базе

Таблица `channel_subs` (user_id × chat_id) обновляется при каждой проверке
гейта — и когда юзер её проходит, и когда нет. Так картина остаётся свежей.

При первом запуске после обновления схема догоняется автоматически: тем, кто
уже прошёл гейт, проставляются все каналы их ГЕО (прошёл гейт = был подписан
на все, иначе бы не прошёл). Повторные запуски бэкфилл не дублируют.

2. Прислать боту сообщение (текст / фото / видео) — так, как должны увидеть юзеры
3. **🧪 Тест себе** — копия придёт админам, видно точный рендер
4. **✏️ Переписать** — если что-то не так
5. **🎯 Тест на 10** — проверка на живых юзерах (потом исключаются из полной)
6. **🚀 Отправить всем** → отчёт: доставлено / заблокировали / ошибок

Заблокировавшие бота помечаются автоматически и больше не получают рассылок.

## Если гейт не пускает подписанного юзера

Запусти `/check` — он покажет по каждому каналу:

```
-1003910322335 — LUCKY LATVIA
  chat: ✅ LUCKY LATVIA (channel)
  bot rights: ✅ admin
  you: ✅ creator
```

Как читать:

| Что видно | Причина | Что делать |
|---|---|---|
| `chat: ❌ chat not found` | неверный `chat_id` | проверить переменную, формат `-100...` |
| `bot rights: ❌ left` | бот не в канале | добавить бота админом |
| `bot rights: ❌ member` | бот участник, но не админ | выдать права администратора |
| `you: ❌ FORBIDDEN` | бот не может читать участников | сделать бота админом |
| всё ✅, но гейт не пускает | кэш старого сообщения | нажать /start заново |

Главная причина в 90% случаев — **бот не админ в канале**. Без прав
администратора `getChatMember` возвращает Forbidden, и бот трактует это
как «не подписан» для всех подряд.

Теперь такие сбои не молчат: при ошибке проверки админам приходит
уведомление с текстом ошибки.
