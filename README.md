# Gate Bot — двойной гейт подписки + бонус-хаб + рассылки

Один бот вместо покупки трафика в каждый канал отдельно.

**Воронка:** FB-реклама → бот → подписка на оба канала ГЕО (казино + беттинг)
→ доступ к бонус-хабу → юзер в базе → рассылки в личку.

Один оплаченный клик = две подписки + контакт в базе.

---

## Что умеет

| Функция | Как работает |
|---|---|
| **Двойной гейт** | Требует подписку на все каналы ГЕО, проверка через `getChatMember` |
| **Мульти-ГЕО** | LV и LT из коробки, новое ГЕО = блок в `config.py` + переменные |
| **Deep-link атрибуция** | `?start=lv_fb_casino_cr3` → geo=lv, source=fb_casino_cr3 |
| **Бонус-хаб** | Категории казино/ставки, офферы из `bonuses.json` |
| **Локализация** | LV → латышский, LT → литовский, английский как фолбэк |
| **Картинка в гейте** | Файл из папки `image/`, отдельно под каждое ГЕО |
| **Трекинг кликов** | Каждое открытие бонуса пишется в БД — видно, что реально интересно |
| **Рассылки** | `/broadcast` с тест-режимом, троттлинг 25 msg/сек |
| **Статистика** | `/stats` — конверсия гейта, разбивка по ГЕО и источникам, топ бонусов |
| **Обновление бонусов** | `/reload` перечитывает JSON без рестарта |

## Деплой на Railway

### 1. Создать бота
@BotFather → `/newbot` → скопировать токен.

### 2. Добавить бота админом в КАЖДЫЙ канал
Без этого `getChatMember` вернёт Forbidden и гейт не заработает.
Достаточно минимальных прав (можно снять всё, кроме присутствия в админах).

### 3. Узнать chat_id каналов
Переслать любой пост из канала боту @getmyid_bot. Формат: `-100xxxxxxxxxx`.
Свой ID для `ADMIN_IDS` — у @userinfobot.

### 4. Залить репозиторий
```bash
git init && git add . && git commit -m "init"
git remote add origin <твой-репо>
git push -u origin main
```
Railway → New Project → Deploy from GitHub repo.

### 5. Подключить Volume (обязательно!)
Railway → Volumes → Add Volume, mount path `/data`.
Затем переменная `DB_PATH=/data/bot.db`.

**Без этого база пользователей сотрётся при первом же редеплое.**

### 6. Прописать переменные
Скопировать всё из `.env.example` в Railway → Variables, подставив свои значения.

### 7. Проверить
Логи должны показать `Бот @yourbot запущен`. Дальше в боте: `/start` → `/links`.

## Ссылки под Facebook-кампании

Команда `/links` в боте выдаёт готовые ссылки. Формат:

```
https://t.me/yourbot?start=lv                    базовая
https://t.me/yourbot?start=lv_fb_casino          казино-креативы LV
https://t.me/yourbot?start=lv_fb_betting         беттинг-креативы LV
https://t.me/yourbot?start=lv_fb_casino_cr3      конкретный креатив
```

Первая часть до `_` — код ГЕО (определяет, какие каналы требовать).
Всё остальное пишется в `source` и видно в `/stats`.

Гейт одинаковый для всех источников внутри ГЕО (оба канала),
но метка позволяет считать конверсию по каждому креативу отдельно
и сегментировать рассылки.

## Картинка в гейте

Положить файл в папку `image/`:

```
image/gate_lv.jpg    для Латвии
image/gate_lt.jpg    для Литвы
image/gate.jpg       общий фолбэк
```

Поддерживаются `.jpg` `.jpeg` `.png` `.webp`. Приоритет: `gate_{geo}` → `gate`.
Файла нет — гейт уйдёт просто текстом, без ошибок.

Текст гейта становится подписью к фото (лимит Telegram — 1024 символа,
текущие тексты укладываются с запасом).

## Языки

Тексты для пользователя лежат в `locales.py`:

| ГЕО | Язык |
|---|---|
| `lv` | латышский |
| `lt` | литовский |
| остальные / не определено | английский |

Админка (`/stats`, `/broadcast`) осталась на русском — она только для своих.
Добавить язык: скопировать блок в `LOCALES` и поменять код ГЕО.

Названия и описания бонусов берутся из `bonuses.json` — там текст пишется
сразу на нужном языке, отдельно для каждого ГЕО.

## Обновление бонусов

Правишь `bonuses.json` → пушишь в репо → Railway передеплоит → `/reload` в боте.
Либо монтируешь файл в Volume и правишь без редеплоя.

```json
{
  "lv": [
    {
      "id": "уникальный_id",
      "brand": "1xBet",
      "title": "Заголовок",
      "description": "Условия",
      "url": "https://твоя-affiliate-ссылка",
      "vertical": "casino",
      "expires": "2026-12-31"
    }
  ]
}
```

`expires` в прошлом → бонус автоматически скрывается.
`/reload` предупредит о тех, что протухают в ближайшую неделю.
Битый JSON не уронит бота — останется последняя рабочая версия.

## Команды админа

| Команда | Что делает |
|---|---|
| `/stats` | Конверсия гейта, ГЕО, источники, топ бонусов, приток за 24ч |
| `/broadcast` | Рассылка: выбор аудитории → сообщение → тест → отправка |
| `/reload` | Перечитать `bonuses.json` |
| `/links` | Готовые deep-link ссылки для рекламы |

### Как делать рассылку

1. `/broadcast` → выбрать ГЕО или «Всем»
2. Прислать боту сообщение (текст / фото / видео) — так, как должны увидеть юзеры
3. **🧪 Тест себе** — копия придёт админам, видно точный рендер
4. **✏️ Переписать** — если что-то не так
5. **🎯 Тест на 10** — проверка на живых юзерах (потом исключаются из полной)
6. **🚀 Отправить всем** → отчёт: доставлено / заблокировали / ошибок

Заблокировавшие бота помечаются автоматически и больше не получают рассылок.
